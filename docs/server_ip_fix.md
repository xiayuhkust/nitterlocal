# 后端服务IP地址访问问题解决方案

## 问题描述
后端服务在本地运行正常（绑定到0.0.0.0:8000），但无法通过43.132.129.242:8000访问。

## 原因分析
1. 43.132.129.242可能不是服务器的实际IP地址
2. 开发环境和服务器之间存在网络连接问题
3. 防火墙可能阻止了8000端口的外部访问

## 解决方案

### 1. 验证服务器的实际IP地址
```bash
# 在服务器上运行以下命令查看实际IP地址
hostname -I
```

### 2. 检查防火墙设置
```bash
# 检查防火墙是否阻止了8000端口
sudo iptables -L -n | grep 8000

# 如果需要，开放8000端口
sudo iptables -A INPUT -p tcp --dport 8000 -j ACCEPT
sudo iptables-save
```

### 3. 确保服务绑定到正确的网络接口
服务已正确配置为绑定到0.0.0.0:8000，这应该允许从所有网络接口访问。

### 4. 使用正确的URL访问服务
使用服务器的实际IP地址或域名访问服务：
```
http://<实际IP地址>:8000/
```

### 5. 重启服务以应用更改
```bash
sudo systemctl restart nitterlocal-backend
```

## 测试连接
```bash
# 在服务器上测试本地连接
curl -v http://localhost:8000/

# 在远程机器上测试连接
curl -v http://<实际IP地址>:8000/
```

## 注意事项
- 如果服务器在云环境中，可能需要在云提供商的控制面板中配置安全组或防火墙规则
- 确保服务器的网络配置允许外部访问8000端口
- 如果使用域名，确保DNS记录正确指向服务器的IP地址
